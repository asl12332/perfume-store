# 🌸 عطور الفاخرة - Luxury Perfume Store

متجر عطور متكامل مع لوحة تحكم للإدارة وصفحات للمتصفح العادي.

---

## 📁 هيكل المشروع

```
perfume-store/
├── src/
│   ├── index.js          ← نقطة البداية (السيرفر)
│   ├── db.js             ← الاتصال بقاعدة البيانات
│   ├── setup-db.js       ← إنشاء الجداول والبيانات التجريبية
│   ├── middleware/
│   │   └── auth.js       ← التحقق من الصلاحيات
│   └── routes/
│       ├── auth.js       ← تسجيل الدخول والخروج
│       ├── store.js      ← المتجر للعملاء
│       └── admin.js      ← لوحة التحكم
├── public/               ← ملفات ثابتة (صور، CSS، JS)
├── .env                  ← متغيرات البيئة
└── package.json
```

---

## ⚙️ طريقة التشغيل

### الخطوة 1 - تثبيت الحزم
```bash
cd perfume-store
npm install
```

### الخطوة 2 - إعداد قاعدة البيانات
تأكد أن PostgreSQL شغال عندك، ثم:
```bash
# أنشئ قاعدة البيانات
psql -U postgres -c "CREATE DATABASE perfume_db;"

# أنشئ الجداول وأضف البيانات التجريبية
npm run setup-db
```

### الخطوة 3 - تعديل .env (اختياري)
```env
DATABASE_URL=postgres://postgres:YOUR_PASSWORD@localhost:5432/perfume_db
SESSION_SECRET=any_secret_key
PORT=3000
```

### الخطوة 4 - تشغيل المشروع
```bash
# وضع التطوير (مع إعادة تشغيل تلقائية)
npm run dev

# أو الوضع العادي
npm start
```

## ✨ المميزات

### المتجر (للعملاء)
- عرض المنتجات مع الفلترة حسب التصنيف
- صفحة تفاصيل كل منتج
- سلة التسوق
- إتمام الطلب مع بيانات التوصيل
- تسجيل دخول وإنشاء حساب

### لوحة التحكم (للإدارة)
- إحصائيات عامة (منتجات، طلبات، عملاء، إيرادات)
- إدارة المنتجات (إضافة، حذف)
- إدارة الطلبات وتحديث حالتها
- عرض المستخدمين المسجلين

---

## 🗄️ الجداول في قاعدة البيانات

- **users** - المستخدمون (عملاء وإداريون)
- **categories** - تصنيفات العطور
- **products** - المنتجات
- **orders** - الطلبات
- **order_items** - تفاصيل الطلبات
- **cart** - سلة التسوق
